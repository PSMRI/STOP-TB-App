# Factory UI (as-built)

How Project Factory wizard chrome is styled. **Musts:** `.cursor/rules/factory-ui.mdc`. **Why:** [ADR-0016](../docs/adr/0016-factory-ui-agents-flow-visual.md). Items CRUD stays on [web-ui](../.cursor/skills/web-ui/SKILL.md) / cream `index.css` defaults.

## Source of truth

Visual language cloned from the `agents_flow` wizard shell (dark zinc panels + indigo accent + per-stage sidebar colors). Do not invent a second Factory palette.

## Form controls

Use **Ant Design** (`antd`) for Project Factory interactive controls, themed via [`factory/antd-theme.ts`](../src/factory/antd-theme.ts) and a single [`FactoryAntdProvider`](../src/factory/FactoryAntdProvider.tsx) around Landing / My Projects / Factory / Design Studio routes (ADR-0018). Do **not** nest extra `ConfigProvider`s in form components. Use Ant `Button`, `Form`, `Input`, `Select`, `Radio`, `Spin`, `Alert`, `Empty`, `Popconfirm`, `Tag`, `Dropdown`, `Avatar`, `List`, `Typography` — **no native** `<button>`, `<input>`, `<textarea>`, or `<select>` for app UI (TipTap contenteditable and structural markup are fine). Pipeline `PhaseRail` / `PhaseStepsBar` and Items CRUD also use Ant controls.

## Idea AI refine

Ideation **Enhance with AI** uses `POST /api/v1/ideas/refine` via Factory LLM (`factory-llm`, ADR-0020). **Domain suggest** uses `POST /api/v1/ideas/suggest-domain` (Lead model; mock keyword classifier when no key). Compare UI: `IdeaEnhanceCompare` / `ArtifactEnhanceCompare` — Ant `Card` pair with equal max-height scroll panes, VS divider, Recommended tag on AI side, choose CTA on each card footer, Markdown on both panes; **Full screen** expands the compare into a viewport modal (`EnhanceCompareFrame`). Enhance control is an Ant Design `Button` pill (`IdeaEnhanceButton`) on the Idea field label **and** in the fullscreen editor toolbar. Idea **Description** edit UX: `IdeaEditorPreview` (structured placeholder + caret) opens Ant `Modal` + lean TipTap toolbar (`IdeaFullscreenEditor`: bold/italic, H2/H3, lists, Enhance with AI; Ant `Button` actions); stores markdown via marked/turndown. Inline TipTap **`IdeaRichEditor`** remains for Discovery/Solution artifact edit (lean toolbar: bold/italic, headings, lists; `focusSelection` scrolls the highlight into view).

## Specialist / BRD / Architecture artifact edit

Discovery war-room specialist review, BRD Review, and Architecture specialist + HLD/LLD review use **Edit** (manual TipTap with lean formatting toolbar; Edit from a highlight selects that span) + **Edit with AI** (instruction prompt → compare via `ArtifactEnhanceCompare` / `POST /api/v1/discovery/refine-artifact`). **Scoped refine:** pick a `##`/`###` section and/or select text in the read-only document or Edit mode (selection wins). A toolbar on the highlight quotes the span and offers **Revise selection** (inline instruction → AI), **Edit** (selected span only — save splices into the artifact; whole-doc TipTap stays on the document **Edit** control), and **Clear**. Revise/Edit sheets use **Back** (keep the highlight) and **Dismiss** (drop the selection) — not Clear, which sounded like wiping the draft. Rendered selections (bold / lists) map to a unique markdown span (whitespace + `*` `_` `` ` `` ignored); missing or duplicate spans error instead of guessing. AI compare can be dismissed with **Clear compare**; the recommended pane is editable before **Use enhanced**; applying a selection edit stays in read-only view. The client sends the fragment as `content` plus `scope` / `full_content` / `section_heading` | `selection_text` so the API (`artifact_refine`) can use the full document as context while returning **only** the revised fragment; the UI still splices locally (`artifact-scoped-refine`) as a safety net. Architecture **Autofix** uses the same splice path: one refine per failing/missing `##` heading (quality rows like `Screen Inventory — Role vocabulary` map to `Screen Inventory`); passing sections are not sent to the model. Whole-document refine remains when **Edit with AI** has no section/selection scope. Architecture refine accepts Solution agent IDs (`solutionArchitect`, `solutionLead`, …). Default view is read-only `MarkdownContent`; Edit toggles the rich editor. Specialist review footer **Ask specialist to rewrite** re-runs the agent (hidden while the selection bar is open — that path is local Revise/Edit). Review screens show the right **Artifacts** rail (`ArtifactsPanel` embedded) for Discovery and Architecture. When Discovery has uploaded documents with extracted text, BRD Review **defaults to compare** via `BrdUploadCompare` (full-width panes; upload is **reference only** — RFP/docs cannot be approved as the BRD; only **Approve Discovery BRD**). Artifacts rail hides during compare. War-room cards and specialist / BRD **Artifact confidence** show band + score (plus a one-line definition on review). Specialist review (Discovery, Architecture, Design) and clarification user-review use a **collapsible** panel (caret toggle; Solid / Held back / Missing start collapsed). Tooltip: **N points short of 100** when under 100; then **h3** sections **Solid**, **Held back by**, **Missing sections**. If score &lt; 100 and `gaps[]` is empty, copy says the run listed no hold-back. Point-level deductions are **not** on the API envelope (`the-project-factory-api`). Low band on BRD notes Approve can be blocked.

Specialist pause titles use the artifact name (e.g. Requirements Analysis) plus specialist · N of M — not “Specialist review / Stage N”. **Discovery clarification** keeps the hub-and-spoke war room visible (compact board above); MCQs + artifact preview sit in a pane below with **Submit clarifications** + **Re-run stage** (hub spoke **clarify**). Specialist **user review** still uses the full review workspace. Specialist review footer is **Ask specialist to rewrite** (optional **Add rewrite notes**; empty notes = `rerun_stage`) and **Accept and merge into Working BRD** (last specialist: **Send to Lead to write the BRD**); Re-run also stays on the war-room header. War-room hub spokes distinguish **Lead review**, **Lead feedback**, **revising**, **clarify**, **you review**, and **Lead merging**. War-room stages are titled `N · Specialist` (parallel: comma-separated names), not “Stage N · reports to lead”. Design markdown review has the same Edit with AI / selection Revise path (`uxStrategist` and other Design agent IDs on refine-artifact). Done on Architecture and Design PATCHes the artifact. Deliverable review (BRD, HLD/LLD, Design proposal) uses the same Lead header grammar; footer **Ask Lead to rewrite** + **Approve** (Accept).

Specialist review and deliverable review layout: one `reviewBody` scroll (document / meta) + pinned `reviewFooter` (actions) so sticky overlays never cover the last lines of content.

Used for BRD Review, HLD/LLD review, artifact viewer, and AI compare panes. ## Auth

Factory wizard requires Keycloak when configured ([ADR-0021](../docs/adr/0021-keycloak-auth.md), skill `keycloak-auth`). Soft-bypass when triad unset. `/factory`, `/my-projects`, and `/settings` are wrapped in `ProtectedFactoryRoute`, which triggers Keycloak `login()` on mount when unauthenticated (no intermediate `/login` page) and returns to the requested path after SSO. Bare `login()` (no deep link) lands on `/`. While Keycloak init / redirect is in flight (and while FactoryPage bootstraps a project), show **`FactoryLoadingScreen`** (hero brand + indigo pulse + status). Role-denied screens stay centered alert + link. Topbar account chip (`FactoryAuthControls`: avatar initials + username menu → Sign out) when Keycloak session is active; logout returns to `/`.

## Do / don’t

- **Do** restyle Factory via `factory-ui` + these tokens
- **Do** use Phosphor icons via `factory/icons.ts` for Pipeline + landing CTA
- **Do** put a Phosphor icon on every labeled action control (`antd` `Button` `icon` prop, or inline icon + label); forward CTAs use `iconPlacement="end"`
- **Do** keep Items / simple CRUD on cream web-ui defaults
- **Don’t** add Tailwind or a parallel token file without updating this knowledge + ADR
- **Don’t** freestyle purple-on-white marketing themes for Factory — use the dark zinc system above
- **Don’t** ship labeled action buttons without an icon
- **Don’t** use native form controls (`button` / `input` / `textarea` / `select`) for app UI — Ant components only


### Design Studio (`/factory/design-studio?projectId=`)

Thin Flow A workspace (ADR-0043 / API Design Studio slices B–C): page list, HTML iframe preview, refine chat, generate-all / sync-to-wizard. Opened from DesignPanel **Open Full Studio**. Not a standalone gallery. **Cross-tab sync** (`studio-wizard-sync`): both surfaces handle `design-reset` (abort in-flight gen/agent, clear queues, reload), `pages-updated` / `sync-to-wizard` (soft page refresh), and `gen-progress` (toolbar generation banner when the other tab is generating). Canvas shows an iframe for any non-stub HTML (not only “complete” HTML). generate-all SSE (`screen-complete` / `brand-guide-complete`) patches page HTML immediately; Studio re-lists pages in `finally` and reloads on wizard `pages-updated` / tab focus so Brand Guide generated in Design Review is not left as **Not generated**. Design Review publishes `pages-updated` and `gen-progress` during generate. Page delete hits the API immediately (not gated on Save); deleting a root cascades resolution variants; toolbar **Undo** restores the session’s last delete batch (then falls back to HTML refine undo). Edit Mode shows **Whole screen edit with AI** in the left inspector with no selection (page-mode `design-agent`).
